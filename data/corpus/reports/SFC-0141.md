# Interactive Authentication by svc-monitor13

Summary

Identity records list certificate as the sole approved method for svc-monitor13. A successful login for svc-monitor13 was recorded on EXT-VPN-08 using password instead. The affected subnet is 10.179.50.0/24.

Detection follow-up

Flag successful logins that do not use the account's expected authentication method. The rule reads `account_id`, `event_type`, `auth_method` and `expected_auth_method` from the authentication log. In this case `mfa_used` varied between events and is not part of the pattern, so the rule must not depend on it.
