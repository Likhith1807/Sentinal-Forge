**Runbook – Distributed Failed Logins on CITRIX‑GW‑03**

1. **Identify the trigger** – An alert fires when **"at least six"** distinct accounts fail to authenticate from the same source host within **"ten minutes"**.  
2. **Gather required fields** – Query the log for **"the username"**, **"the login result"**, **"the event time"**, and **"the host the request originated from"** for each failure event.  
3. **Validate the pattern** – Confirm that the failures involve at least six unique usernames (e.g., zosei, hiro.chen) and that none resulted in a successful login. Ensure the time span between the earliest and latest **"the event time"** does not exceed **"ten minutes"**.  
4. **Check source consistency** – Verify that **"the host the request originated from"** is the same for all events and that the source IP belongs to the 10.158.10.0/24 subnet.  
5. **Escalate** – If the conditions are met, create a ticket referencing CITRIX‑GW‑03 and begin containment procedures.
