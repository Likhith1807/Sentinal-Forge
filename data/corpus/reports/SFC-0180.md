**Runbook – Detect Missing MFA on Mandatory Accounts**  
Ticket: INC-57730 | Severity: medium | Analyst: K. Sorensen  

**Purpose** – Trigger an alert when a sign‑in succeeds without the required second factor for an account whose policy mandates it.

**Steps**  
1. Query the authentication logs for records where **"event_type"** = *login_success*.  
2. Filter those records to include only entries that contain the fields **"account_id"**, **"mfa_used"**, and **"mfa_required"**.  
3. Identify rows where **"mfa_required"** = true **and** **"mfa_used"** = false; ignore the value of **"auth_method"** (it is incidental).  
4. If any matching record originates from the subnet 10.203.51.0/24, generate a detection alert referencing the affected **"account_id"** (e.g., priya.rahman).  

**Outcome** – The rule will fire on a successful sign‑in with no second factor when the account’s policy mandates it, enabling rapid response to policy violations.
