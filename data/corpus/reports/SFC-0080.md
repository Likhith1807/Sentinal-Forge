**Runbook – INC-93531: Detecting Excessive Failed Sign‑Ins**

1. Retrieve authentication logs for the source host (e.g., JUMP-18) and isolate records with a failed “the sign-in outcome”.  
2. Count distinct values of “the account identifier” in those records; the detection should trigger when a single host generates failed sign‑ins for **"more than 5"** different accounts within a **"15-minute"** window.  
3. Confirm each record includes “the event time” and “the host the request originated from” to satisfy the rule’s data requirements.  
4. If the condition is met, generate an alert, link it to ticket **INC-93531**, and assign to the on‑call analyst.  
5. Record the observed accounts (e.g., ochen, mkowalski, rosa2) and note the approximate duration (about 12 minutes) for future rule tuning.
