Subject: Detection rule request – failed auth across multiple accounts (INC-23264)

Team,

During the handoff from P. Banerjee I observed activity on SSO‑GW‑15 where the host attempted a small password list against several directory accounts. Over roughly 12 minutes the host touched 8 different accounts, including ktanaka and yusuf.haddad, and none succeeded.

We need an alert that fires when **no fewer than 4** distinct accounts fail to authenticate from the same source host within **10 minutes**. To evaluate the rule we must capture **the account being authenticated**, **the success/failure status of each event**, **the time of each attempt** and **the originating host**. For scoping, **how the account authenticated** is not relevant and should be excluded from the rule logic.
