# Sign-In Without a Second Factor: tara.kowalski

- **Report ID:** SFC-0169
- **Source:** Synthetic corpus report (family F-B5-005)
- **ATT&CK Technique:** T1556 (Modify Authentication Process), T1621 (MFA Request Generation)

## Narrative

tara.kowalski is required to use multi-factor authentication by policy. tara.kowalski logged in from RDP-EDGE-15 and the event records that MFA was not used. Earlier the same day the account had 9 unremarkable successful logins.

## Recommended detection

- Flag any successful login lacking MFA on an MFA-required account.
- The rule reads `account_id`, `event_type`, `mfa_used` and `mfa_required` from the authentication log.
- In this case `auth_method` varied between events and is not part of the pattern, so the rule must not depend on it.
