**Runbook – Alert for Rapid Multi‑Host Logins**  
Ticket: INC-46508 | Severity: high | Analyst: K. Sorensen  

**Purpose:** Detect when a single user authenticates from “2+” distinct hosts within “ten minutes”.

**Steps:**  
1. **Gather logs** for the target period and filter on “the account identifier”.  
2. **Extract** “the sign-in outcome”, “the event time”, and “the originating host” for each record.  
3. **Group** entries by “the account identifier” and sort by “the event time”.  
4. **Identify** any sequence where two successful outcomes (“the sign-in outcome”) occur on different “the originating host” values and the time delta between them is ≤ “ten minutes”.  
5. **Raise** an alert if the condition is met; do not consider “the authentication method” when evaluating.  
6. **Document** the affected user (e.g., abrennan), source hosts (e.g., SSO‑GW‑04, JUMP‑07), and subnet (10.214.148.0/24) for incident tracking.
