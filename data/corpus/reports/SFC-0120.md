**Runbook: Detect Concurrent Logins**

1. Pull authentication logs for the target account (e.g., wen3). Verify each record includes **"the username"**, **"the login result"**, **"the event time"** and **"the host the request originated from"**. Omit any field for **"the originating IP"**.  
2. Sort the entries by **"the event time"** and search for two successful entries (**"the login result"** = success) that occur within **"fifteen minutes"**. The two entries must originate from **"no fewer than two"** distinct hosts.  
3. When the pattern is detected, open a ticket referencing **INC-25441**, assign it to the on‑call engineer (K. Sorensen), and record the involved hosts (e.g., WIN-LAB-17 and RDP-EDGE-06) with their timestamps.  
4. Follow escalation procedures if concurrent use is confirmed.
