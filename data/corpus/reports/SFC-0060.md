**Runbook – Detect multiple failed logins from a single host**

9. Identify the source host that generated the authentication attempts and confirm it matches the host the request originated from.  

6. Gather authentication events for the preceding fifteen minutes, ensuring each record includes the account being authenticated, whether each attempt succeeded or failed, the event time and the host the request originated from.  

‑ Count distinct accounts that have failed logins from that host; if the count reaches four or more, trigger an alert.  

‑ Do not factor in how the account authenticated; this attribute is incidental and should not be used in the detection logic.  

‑ Document the alert, reference Ticket INC-64164, and assign follow‑up to the analyst listed.
